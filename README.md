VISUAL DESIGN DIRECTION

The visual identity should balance:

Clean + Bold + Creative + Professional + Personal

Do not make it look like a generic corporate analytics website.

Do not make it look like a cyberpunk AI portfolio either.

The ideal aesthetic is closer to a modern editorial technology portfolio.

Light Mode

Use a warm, sophisticated light background rather than pure white everywhere.

Possible palette direction:

Soft off-white / warm neutral background
Near-black primary text
Deep charcoal secondary text
One distinctive accent color
Very subtle secondary accent

The accent should feel modern and intelligent without becoming neon.

Potential accent directions:

Electric blue
Deep cobalt
Muted violet
Teal
Blue-violet

Choose one primary accent and use it consistently.

Dark Mode

Use a deep charcoal / near-black background rather than pure black.

Use:

Off-white text
Muted gray secondary text
The same accent color from light mode
Very subtle gradients
Fine borders
Soft glow only where appropriate

The two themes should feel like the same personal brand, not two completely different websites.

TYPOGRAPHY

Typography should be a major part of the design.

Use a modern sans-serif typeface with strong character for headings and a highly readable typeface for body text.

Very large hero headline
Medium section headings
Compact supporting text
Small metadata labels

Avoid excessive bold text everywhere.

Consider subtle typographic details such as:
